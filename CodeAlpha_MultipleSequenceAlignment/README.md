# Myoglobin Multiple Sequence Alignment and Phylogenetic Analysis

This project presents a **Multiple Sequence Alignment (MSA)** and evolutionary analysis of five vertebrate myoglobin proteins using **UniProtKB** and **Clustal Omega**.

## Tools Used
- UniProtKB
- Clustal Omega

## Analysis Performed
- FASTA sequence retrieval
- Multiple Sequence Alignment
- Conserved region identification
- Guide tree analysis
- Phylogenetic tree analysis

## Protein Sequences
Mouse, Rat, Bovine, Human, and Pig myoglobin sequences.

## Output
The report includes screenshots, alignment results, conserved regions, guide tree, phylogram, phylogenetic tree, and interpretation.
