# Protein Analysis Report

## Overview
Bioinformatics analysis of **Hemoglobin subunit beta (HBB)** from *Homo sapiens* using UniProtKB and NCBI BLASTP.

## Protein Information
- **Protein:** Hemoglobin subunit beta
- **UniProt Accession:** P68871
- **Gene:** HBB
- **Organism:** *Homo sapiens*
- **Length:** 147 amino acids

## Analysis
The HBB protein sequence was retrieved from **UniProtKB** in FASTA format and analysed using **NCBI BLASTP** against the ClusteredNR database.

## Results
- **Query Coverage:** 100%
- **Sequence Identity:** 86%
- **E-value:** 2 × 10⁻⁹⁷
- **Gaps:** 0%

## Conclusion
The BLASTP results show strong sequence conservation and significant similarity with homologous hemoglobin proteins.
